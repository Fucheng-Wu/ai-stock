# 子代理技能

当前工作台按角色提供以下项目技能：

- `stock-520/SKILL.md` → `stock-analyst`：520 均线战法三步分析和规则证据解读；
- `web-research/SKILL.md` → `web-researcher`：各领域公开信息检索、时效判断和来源引用。

网关在创建子代理时直接读取其专属技能文件，并将正文注入系统提示，股票分析和信息检索角色不共享技能。
`stock-screener` 使用专用角色提示和两个快照查询工具，不注入上述技能，也不获取文件读取能力。
模型不需要也不允许使用文件读取工具加载技能。普通 Agent 不加载这些技能。
不会自动加载全局技能、包内技能、其他项目技能或项目 AGENTS.md。

技能目录遵循 Agent Skills 格式，frontmatter 包含 `name` 和 `description`。
`disable-model-invocation: true` 可以停用正文注入。文件修改在下一次子代理调用时生效；
不会改变已经运行中的子代理。缺失必需文件会明确报错，不退回全局同名技能。

新增技能目录或在角色文件中设置 `skills: ["*"]` 都不会扩大运行时范围；
如要扩展角色能力，需由开发者修改 `src/lib/agent-policy.ts` 的明确列表。
模板只用于格式参考，不会自动加载到模型会话。
