# 持仓总资产回显与持仓比例设计

## 目标

账户总资产按登录用户持久化，修改后再次打开弹窗时回显原值。持仓列表展示每只股票最近分析市值占账户总资产的比例。

## 数据与计算

- 为 `stock_account` 查询增加显式 MyBatis `resultMap`，映射 `user_id` 与 `total_assets`。
- 持仓列表读取当前用户账户总资产及每条持仓的最新分析快照。
- 从快照 `holding.marketValue` 取得最近分析市值，计算 `marketValue / totalAssets * 100`，保留两位小数。
- 没有账户总资产、没有快照或快照没有市值时，持仓比例返回空值。
- 比例只作为列表响应字段，不写入持仓表；总资产变化后列表按最新总资产重新计算。

## 前端交互

- “账户总资产”弹窗打开时调用账户查询接口，并回显已保存值。
- 保存总资产成功后刷新持仓列表。
- 持仓列表新增“持仓比例”列，有值显示百分比，无值显示“暂无”。

## 测试

- 回归测试验证账户查询使用显式字段映射。
- 服务测试覆盖正常比例、总资产为零及空值情况。
- 运行股票相关后端测试、后端打包和前端生产构建。
